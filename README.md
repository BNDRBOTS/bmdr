# BMDR

BMDR is a static, mobile-first browser practice space for self-guided bilateral stimulation. It combines a moving visual anchor, optional left-right audio, adjustable visual and audio pacing, two movement paths, four palettes, and automatic pause when the page is hidden.

## Architecture

- Public hosted browser app: immediately usable without purchase or account
- Paid product: downloadable/offline BMDR file
- Checkout and download delivery: Gumroad
- Backend: none
- Build step: none

The marketing site loads the public practice space through the relative `app.html` path. Both `app.html` and `bmdr.html` also work as standalone files. The optional paid download is available at <https://bndrllc.gumroad.com/l/bemdr>.

## Included files

`index.html`, `app.html`, `bmdr.html`, `site.css`, `site.js`, `legal.css`, `terms.html`, `privacy.html`, `refunds.html`, and `support.html`.
